# Attila Szakacs-Bertok

I work on [AxoSyslog](https://github.com/axoflow/axosyslog) at [Axoflow](https://axoflow.com).
Most of my code is C in the syslog-ng / AxoSyslog core, plus Python tooling around its configuration grammar.

## Things I made

- [axosyslog-cfg-helper](https://github.com/alltilla/axosyslog-cfg-helper) - look up AxoSyslog drivers and their options from the command line
- [axosyslog-cfg-diff-pr](https://github.com/axoflow/axosyslog-cfg-diff-pr) - GitHub Action that flags config grammar changes in an AxoSyslog PR
- [neologism](https://github.com/alltilla/neologism) - dynamically modifiable context-free grammar in Python, used to build axosyslog-cfg-helper
- [prettier-plugin-syslog-ng](https://github.com/alltilla/prettier-plugin-syslog-ng) - Prettier plugin for syslog-ng configuration files
